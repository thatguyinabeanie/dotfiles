# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please follow these steps:

1. **Do Not** open a public issue
2. Email the vulnerability details to [your-email]
3. Include:
   - **Description**: The vulnerability
   - **Steps**: How to reproduce
   - **Impact**: Potential impact
   - **Fix**: Suggested fix (if any)

## Security Measures

This repository:

- **Gitleaks**: Used for secrets scanning
- **Trivy**: Employed for vulnerability scanning
- **CodeQL**: Implements CodeQL analysis
- **Dependabot**: Used for dependency updates

## Supported Versions

Only the latest version is supported with security updates.
