# LaunchAgents

This directory contains LaunchAgents that are installed by chezmoi to automate various tasks.

## Available LaunchAgents

### Obsidian Launcher (`com.obsidian.launcher.plist`)

Automatically launches Obsidian when you log in.

### Homebrew Upgrade (`com.homebrew.upgrade.plist`)

Automatically runs `brew upgrade` on a daily schedule (10:00 AM by default).

- Logs are stored in `~/.local/share/homebrew/upgrade.log`
- The schedule can be customized by editing the `StartCalendarInterval` section in the plist file

## Managing LaunchAgents

You can manually control these LaunchAgents with the following commands:

```bash
# Load (start) a LaunchAgent
launchctl load ~/Library/LaunchAgents/com.homebrew.upgrade.plist

# Unload (stop) a LaunchAgent
launchctl unload ~/Library/LaunchAgents/com.homebrew.upgrade.plist

# Check if a LaunchAgent is running
launchctl list | grep com.homebrew.upgrade
```

## Customizing the Schedule

To change the schedule for the Homebrew upgrade:

1. Edit the `MISSION_CONTROL/Library/LaunchAgents/com.homebrew.upgrade.plist.tmpl` file
2. Modify the `StartCalendarInterval` section
3. Run `chezmoi apply` to update the LaunchAgent
4. Reload the LaunchAgent with `launchctl unload ~/Library/LaunchAgents/com.homebrew.upgrade.plist && launchctl load ~/Library/LaunchAgents/com.homebrew.upgrade.plist`

### Example Schedules

#### Run weekly on Sunday at 9:00 AM

```xml
<key>StartCalendarInterval</key>
<dict>
    <key>Hour</key>
    <integer>9</integer>
    <key>Minute</key>
    <integer>0</integer>
    <key>Weekday</key>
    <integer>0</integer>
</dict>
```

#### Run every 3 hours

```xml
<key>StartInterval</key>
<integer>10800</integer>
```

For more information on LaunchAgent configuration, see the [launchd.plist manual](https://www.manpagez.com/man/5/launchd.plist/).
