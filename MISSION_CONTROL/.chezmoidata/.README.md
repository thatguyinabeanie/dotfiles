This directory contains data files used by Chezmoi to manage dotfiles and configuration.

- **homebrew.yaml** - Defines all Homebrew packages, casks, and taps to be installed.
- **platform.yaml** - Contains platform detection results and OS-specific settings.
- **mise.yaml** - Configuration for mise runtime manager (tools and versions).
- **dot_shell_registry.yaml** - Registry of shell aliases, functions, and environment variables.

## 🗂️ Data Files

- **homebrew.yaml** - Defines all Homebrew packages, casks, and taps to be installed
- **platform.yaml** - Contains platform detection results and OS-specific settings
- **mise.yaml** - Configuration for mise runtime manager (tools and versions)
- **treesitter.yaml** - Neovim Treesitter language parsers configuration

## 🔄 Variable Usage

These variables can be accessed in templates using the following syntax:

```jinja
{{ .homebrew.packages.cli }}  <!-- Access CLI packages from homebrew.yaml -->
{{ .platform.is_darwin }}     <!-- Check if running on macOS -->
{{ .mise.tools.node }}        <!-- Access Node.js version from mise.yaml -->
```

## 🌱 Environment-Specific Variables

During installation, chezmoi will prompt for several user-specific values that are stored in `.chezmoi.toml`. These can be referenced alongside the data from this directory:

```jinja
{{ if .work_environment }}
# Work-specific configuration
{{ else }}
# Personal configuration
{{ end }}
```

## 🛠️ Adding New Data

When adding new data files:

1. Create a YAML file with a descriptive name
2. Use structured data with clear organization
3. Document the purpose at the top of the file
4. Reference in templates using the filename as the first key (e.g., `.filename.key`)

For more information, see the [chezmoi documentation on template data](https://www.chezmoi.io/user-guide/templating/).
