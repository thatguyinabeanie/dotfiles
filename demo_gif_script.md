# Dotfiles Demo GIF Script

This script outlines what should be captured in a GIF demonstration of the dotfiles in action.

## Sequence (15-20 seconds total)

1. **Start with terminal opening** (1-2 seconds)
   - Show the terminal with the custom prompt
   - Pokemon system info display appears

2. **Nushell in action** (3-4 seconds)
   - Type a few commands showing Nushell's unique features
   - Show tab completion and syntax highlighting
   - Demonstrate a custom alias

3. **Tmux session management** (3-4 seconds)
   - Create a new tmux window
   - Split panes
   - Show the custom status bar with Catppuccin theme

4. **Neovim editing** (4-5 seconds)
   - Open a file in Neovim
   - Show syntax highlighting with Catppuccin theme
   - Demonstrate a few quick edits with LSP features
   - Show a git integration feature

5. **Theme switching** (3-4 seconds)
   - Show switching between Catppuccin flavors (if possible)
   - Demonstrate how the entire environment updates

## Technical Notes

<!-- markdownlint-disable MD013 -->
- Use a screen recording tool like [Peek](https://github.com/phw/peek) (Linux), [Kap](https://getkap.co/) (macOS), or [ScreenToGif](https://www.screentogif.com/) (Windows)
<!-- markdownlint-enable MD013 -->
- Optimize the GIF to keep file size reasonable (under 5MB if possible)
- Consider adding subtle captions to highlight key features
- Record at 1280x720 resolution for a good balance of quality and file size
