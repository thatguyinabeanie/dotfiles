# Dotfiles Server

This repository includes a Next.js server to showcase the dotfiles. The server is contained entirely within the `.server` directory.

## Running the Server

To run the server, you have several options:

### 1. Using the start script

```bash
cd .server
./start-server.sh
```

This will install dependencies and start the development server.

### 2. Using Docker

```bash
cd .server
./docker-start.sh
```

This will build and start the server in a Docker container.

### 3. Manual setup

```bash
cd .server
npm install
npm run dev
```

## Server Features

- Modern UI built with Next.js and Tailwind CSS
- Responsive design that works on all devices
- API endpoints to get information about the dotfiles
- Showcases the dotfiles configuration and features

## Directory Structure

All server files are contained within the `.server` directory:

```
.server/
├── src/                # Source code
│   ├── app/            # Next.js App Router
│   ├── components/     # React components
│   └── styles/         # CSS styles
├── public/             # Static assets
├── Dockerfile          # Docker configuration
├── docker-compose.yml  # Docker Compose configuration
├── package.json        # Dependencies and scripts
└── README.md           # Server documentation
```

## Updating the Server

To update the server when the dotfiles repository changes:

```bash
cd .server
./update-server.sh
```

This will pull the latest changes, install dependencies, build the application, and restart the server if it's running with PM2.
